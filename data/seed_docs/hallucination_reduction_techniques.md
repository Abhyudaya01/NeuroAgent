# Hallucination Reduction Techniques in LLM Systems

Hallucination reduction in large language model systems is usually approached as a pipeline problem rather than a single-model problem. Retrieval-augmented generation (RAG) is the classic example. Lewis et al. introduced RAG as a hybrid architecture that combines a parametric generator with a non-parametric retriever over an external corpus, which improves factuality because the model conditions generation on retrieved evidence rather than only on internal memorized weights (Lewis et al., 2020, arXiv:2005.11401). In practice, this means an agent first retrieves relevant passages, then cites or conditions on those passages when answering. A concrete example is enterprise question answering: if the retriever surfaces policy text or product documentation, the agent can ground its answer in current documents instead of guessing from stale pretraining knowledge.

RLHF is another major technique, but it addresses hallucination indirectly through preference optimization and reward modeling rather than explicit grounding. InstructGPT showed that models fine-tuned with supervised demonstrations and reinforcement learning from human feedback are more aligned with user intent and less likely to produce obviously fabricated or unsafe content than purely next-token-trained models (Ouyang et al., 2022, arXiv:2203.02155). A practical example is domain-specific assistant tuning: raters can down-rank answers that sound fluent but unsupported, teaching the policy to prefer hedged or evidence-seeking responses over confident fabrication.

Self-correction methods try to detect and repair hallucinations after an initial draft. Self-Refine is a good example: the same model generates an answer, critiques it, and then revises it iteratively using its own feedback (Madaan et al., 2023, arXiv:2303.17651). In a support-agent setting, the first pass may answer too broadly, the feedback stage may flag unsupported claims, and the refinement stage can rewrite the answer to cite retrieved snippets or remove uncertain assertions. Reflexion-style verbal feedback does something similar in agent settings by storing textual lessons from failures and using them in future attempts (Shinn et al., 2023, arXiv:2303.11366).

Constrained decoding reduces hallucination by limiting what the model is allowed to emit. The simplest version is structured decoding against a schema such as JSON Schema or function signatures, which prevents the model from inventing arbitrary fields or malformed outputs. More advanced constrained decoding ties generation to a permitted vocabulary, grammar, or extraction target. A concrete example is medical information extraction: forcing the model to emit only schema-compliant ICD fields or enumerated labels can prevent it from fabricating unsupported free-text diagnoses. Constrained decoding does not guarantee factuality by itself, but it sharply reduces a class of format-level hallucinations and unsupported elaboration.

Chain-of-thought (CoT) can also reduce hallucination when used carefully. Standard CoT often improves reasoning quality by encouraging intermediate decomposition (Wei et al., 2022, arXiv:2201.11903). Self-consistency improves on greedy CoT by sampling multiple reasoning paths and selecting the most consistent final answer, which reduces brittle one-path failures on reasoning-heavy tasks (Wang et al., 2022, arXiv:2203.11171). In retrieval-heavy agents, evidence-aware CoT is most useful when the reasoning trace is explicitly anchored to retrieved facts, because free-form chain-of-thought without grounding can still rationalize hallucinated conclusions.

In modern agent systems, the strongest hallucination mitigation usually comes from combining these techniques: retrieval for grounding, RLHF or preference tuning for aligned behavior, self-correction for post-hoc repair, constrained decoding for output discipline, and CoT or self-consistency for better reasoning under evidence.
