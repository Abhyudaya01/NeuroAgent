# Reflexion and Verbal Reinforcement Learning

Reflexion ("Reflexion: Language Agents with Verbal Reinforcement Learning", Shinn et al., 2023, arXiv:2303.11366) is one of the strongest examples of improving agent reliability without gradient updates. The method replaces weight-space reinforcement learning with language-space reinforcement. Instead of fine-tuning a policy after each mistake, the agent writes down what went wrong, stores that reflection in memory, and conditions future attempts on that verbal feedback. This design is especially relevant for LLM agents because many practical deployments cannot afford online fine-tuning, but they can afford to preserve trajectories, rewards, and self-critique across trials.

The Reflexion framework has three explicit components. The actor is the main decision-making LLM that performs reasoning or action selection. The evaluator produces the feedback signal; depending on the task, this can be a scalar reward, unit tests, environment success, or an externally supplied critique. The self-reflection module converts that feedback into natural-language lessons that are stored in episodic memory and injected into future attempts. The paper calls this verbal reinforcement learning because the update is represented as text rather than as a parameter change. In practice, the episodic memory stores lessons like "I assumed the object was already picked up" or "the answer failed because the supporting evidence came from the wrong article."

One of the clearest gains appears in AlfWorld, a sequential decision-making benchmark where agents must complete household tasks over long action horizons. Reflexion agents dramatically improve over ReAct-style baselines because they stop repeating the same mistakes. Secondary summaries of the paper's Figure 3 report that after 12 trials, Reflexion reaches about 97% success while the ReAct baseline plateaus around 75%. Another summary of the paper reports that Reflexion solves 130 out of 134 AlfWorld tasks. The reliability story is more interesting than the raw number: the paper argues that self-reflection specifically reduces hallucination-style errors, such as believing an object has been picked up or assuming a tool action succeeded when it did not.

HotPotQA is the reasoning-side demonstration. The paper studies both CoT-style reasoning agents and ReAct-style retrieval agents. Here Reflexion again helps because the agent can preserve why a multi-hop reasoning attempt failed. Secondary summaries of the results report about 51% success on the search-based HotPotQA environment and roughly a 20-point improvement over non-learning baselines across trials. Just as important, the paper's ablation reportedly shows that episodic memory alone gives only modest gains, while explicit self-reflection adds about 8 additional points. That ablation is critical for agent design: merely storing old trajectories is not enough. The system improves most when it turns failures into compact, task-relevant advice.

The paper also includes coding results, and those help explain why Reflexion generalizes. In code generation, the evaluator can be very concrete: unit tests either pass or fail. Reflexion uses that signal to produce textual debugging notes and then tries again. On HumanEval Python, the paper reports 91.0% pass@1, exceeding the cited GPT-4 baseline of 80.1%. Although your current seed document request focuses on agents rather than code, the same design principle carries over: critic feedback becomes more effective when it is specific, test-like, and easy to convert into a targeted reflection.

For memory architectures, Reflexion is important because it treats memory as behaviorally useful, not just archival. The memory store contains short natural-language lessons that directly alter later decision-making. That makes it a form of episodic memory with credit assignment. In an agent workflow, the most valuable memories are often not raw transcripts but distilled error analyses: which retrieval query was too broad, which evidence was missing, which action assumption was false, or which benchmark criterion was violated. Reflexion's contribution is to show that a lightweight memory loop can produce consistent gains without retraining the base model.

In practical systems, the Reflexion lesson is straightforward: if an agent has retries, those retries should not be identical. They should be conditioned on explicit verbal feedback, stored in memory, and used to narrow future search or deepen future analysis. That is the core idea of verbal reinforcement learning, and it remains one of the most actionable reliability patterns for LLM agents.
