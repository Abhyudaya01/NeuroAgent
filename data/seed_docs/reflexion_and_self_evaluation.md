# Reflexion, Verbal Reinforcement Learning, and Self-Evaluation in LLM Agents

Reflexion is one of the clearest formulations of self-evaluation for language agents. Shinn et al. describe Reflexion as a framework in which the agent does not update model weights after failure; instead, it writes linguistic reflections about what went wrong and stores them in episodic memory for subsequent attempts (Shinn et al., 2023, arXiv:2303.11366). This is why the paper calls the method verbal reinforcement learning: the reinforcement signal is converted into natural-language feedback rather than gradients. The architecture is appealing for agent systems because it can improve multi-step behavior without requiring expensive fine-tuning loops after each environment interaction.

The paper is especially important because it makes the feedback pipeline explicit. A Reflexion agent typically has three components: an actor that attempts the task, an evaluator that scores the attempt using either an external reward or an internal critique, and a self-reflection module that turns failure information into reusable textual guidance. That reflective text is then injected into future context. In code generation, for example, failed unit tests can be summarized as concrete lessons such as “I forgot an edge case for empty inputs” or “I misused the API signature.” On the next trial, the actor conditions on those lessons instead of starting from scratch.

One notable result in the Reflexion paper is the reported HumanEval improvement, where Reflexion surpasses a strong baseline by using trial feedback plus self-reflection. More generally, the paper shows that different forms of feedback can be verbalized: scalar rewards, environment failures, and free-form critiques can all be transformed into memory entries. This makes the method flexible for autonomous agents operating with tools, APIs, compilers, browsers, or task-specific verifiers.

Verbal reinforcement learning is useful because it turns sparse supervision into an interpretable memory trace. Unlike hidden-state adaptation or pure black-box retries, reflections are inspectable. A research agent can record statements like “The search result was too generic; prioritize peer-reviewed sources” or “The retrieved passages discussed memory architectures broadly, but not hallucination specifically.” This kind of textual memory is valuable not only for performance but also for debugging and evaluation, because downstream failures can be tied back to concrete reflections.

Reflexion is closely related to broader self-evaluation methods such as Self-Refine, where a model generates, critiques, and revises its own answer iteratively (Madaan et al., 2023, arXiv:2303.17651). The difference is that Reflexion is more agentic and trial-oriented: it explicitly supports repeated interaction with an external environment and stores lessons across attempts. In multi-turn tool-using agents, this is critical. The model may fail because it used the wrong tool, trusted a weak source, or ignored an earlier result. A self-evaluation loop can expose each of those failure modes and convert them into future guidance.

For LLM agents, the most practical takeaway is that self-evaluation should be structured. A good critic should score dimensions such as factual grounding, source reliability, completeness, and specificity; then the reflection system should convert low scores into short actionable verbal lessons. That combination makes agent retries more targeted and much easier to analyze than naive repeated prompting.
